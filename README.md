# ClipLab — Gaming Clip Studio

Een statische, Nederlandstalige inspiratie- en editgids voor gamingclips.

## Lokaal bekijken
Open `index.html` in je browser.

## Publiceren via GitHub + Render
1. Maak op GitHub een nieuwe repository, bijvoorbeeld `cliplab`.
2. Upload **de inhoud** van deze map naar de hoofdmap van de repository:
   - `index.html`
   - `render.yaml`
   - `README.md`
3. Ga naar [Render](https://render.com/) en kies **New → Blueprint**.
4. Koppel je GitHub-account en selecteer de repository.
5. Render leest `render.yaml` en maakt de Static Site aan.
6. Na de deploy krijg je een publieke `.onrender.com`-link.

Je kunt ook **New → Static Site** kiezen en handmatig instellen:
- Build command: leeg laten
- Publish directory: `.`

## Functionaliteit
- Responsive layout voor mobiel, tablet en desktop.
- Zoek- en categorie-filter voor inspiratiebronnen.
- Links naar gamingclips en zoekresultaten per game.
- Clip-analyse en creator-profiel met kopieerfunctie.
- Lengtemeter en export-checklist.
- Formulieren en checklist worden lokaal in de browser opgeslagen; er is geen backend nodig.

## Let op
De externe websites en hun inhoud worden door hun eigen beheerders beheerd. Gebruik clips als inspiratie en controleer toestemming/rechten voordat je andermans beeldmateriaal opnieuw publiceert.
